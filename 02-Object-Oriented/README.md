## Key Concepts

### Classes and Objects
- **Class**: Blueprint or template for creating objects
- **Object**: Instance of a class with its own state
- **Constructor**: Special method for object initialization

### Relationships
- **Inheritance (IS-A)**: `extends` keyword, code reuse, polymorphism
- **Composition (HAS-A)**: Object references, building complex objects

### Abstraction
- **Interfaces**: Define contracts, multiple inheritance
- **Abstract Classes**: Partial implementation, single inheritance

### OOP Principles
- **Encapsulation**: Data hiding with private fields and public methods
- **Polymorphism**: One interface, multiple implementations
- **Inheritance**: Code reuse through class hierarchies

### Modern Java Features
- **Enums**: Type-safe constants
- **Records** (Java 14+): Immutable data classes
- **Sealed Classes** (Java 17+): Controlled inheritance
