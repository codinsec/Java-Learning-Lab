## Key Concepts

### Memory Management
- **Stack**: Stores primitive values and object references (fast, limited size)
- **Heap**: Stores actual objects and arrays (larger, slower access)

### Data Types
- **Primitives**: `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`
- **Wrappers**: `Byte`, `Short`, `Integer`, `Long`, `Float`, `Double`, `Character`, `Boolean`

### Control Flow
- Conditionals: `if`, `if-else`, `switch`
- Loops: `for`, `while`, `do-while`, enhanced `for`
- Control: `break`, `continue`, labels

### Collections
- **Arrays**: Fixed-size, indexed collections
- **ArrayList**: Dynamic-size list implementation
- **HashMap**: Key-value pair storage
