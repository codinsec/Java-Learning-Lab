# Java Learning Lab

A comprehensive, structured learning repository for mastering Java from fundamentals to professional Spring Boot development.

## 🎯 Overview

This repository provides a step-by-step learning path covering:
- **Java Fundamentals** (JDK 17/21+)
- **Object-Oriented Programming**
- **Advanced Java** (Functional Programming, Concurrency)
- **Java Ecosystem** (Maven, Gradle, Spring Context)
- **Data Access** (JDBC, Hibernate, JPA)
- **Web Development** (Spring Boot, REST APIs, Security)
- **Testing & Architecture** (JUnit, SOLID, Design Patterns)

## 📚 Learning Structure

The repository is organized into 7 main sections, each containing multiple topics:

1. **01-Fundamentals/** - Java language basics
2. **02-Object-Oriented/** - OOP principles and design
3. **03-Advanced-Java/** - Modern Java features
4. **04-Java-Ecosystem/** - Build tools and frameworks
5. **05-Data-Access/** - Database integration
6. **06-Web-Development/** - Spring Boot REST APIs
7. **07-Testing-Architecture/** - Professional practices

See [roadmap.md](./roadmap.md) for the complete learning path and detailed topic breakdown.

## 🚀 Getting Started

### Prerequisites
- **JDK 17 or 21+** (recommended: JDK 21 LTS)
- **Maven 3.6+** or **Gradle 7.0+**
- **IDE** (IntelliJ IDEA, Eclipse, or VS Code with Java extensions)
- **Git** for version control

### Repository Structure
```
Java-Learning-Lab/
├── 01-Fundamentals/
│   ├── 01-Variables-DataTypes/
│   ├── 02-Conditionals-Loops/
│   └── ...
├── 02-Object-Oriented/
│   ├── 06-Classes-Objects-Constructors/
│   └── ...
└── ...
```

Each topic folder contains:
- Maven/Gradle project structure
- Code examples
- README.md with explanations
- Build configuration files

## 📖 How to Use This Repository

1. **Follow the sequence** - Topics are designed to build upon each other
2. **Read the README** - Each topic folder has a detailed README
3. **Run the examples** - Execute code to understand concepts
4. **Practice** - Modify examples and experiment
5. **Complete exercises** - Some topics include practice exercises

## 🛠️ Project Standards

- **Build Tool:** Maven (default) or Gradle
- **Package Naming:** `com.learning.lab.[topic]`
- **Java Version:** JDK 17/21+
- **Documentation:** All README files in English

## 🔄 Git Workflow

This repository follows a structured Git workflow:

- **main** - Stable, production-ready code
- **develop** - Active development branch
- **feature/{topic-name}** - Individual topic branches

After completing each section:
1. Create feature branch
2. Commit changes with descriptive messages
3. Create and push version tags
4. Merge to main

See [roadmap.md](./roadmap.md) for detailed Git workflow instructions.

## 📝 Commit Convention

Commits follow this format:
```
[TOPIC] brief description

Examples:
[STREAMS] basic filter and map examples
[JPA] add one-to-many relationship between User and Post
[FUNDAMENTALS] add variables and data types examples
```

## 🏷️ Version Tags

Tags are created after completing each section:
- Format: `v{section}.{topic}.{increment}`
- Example: `v1.0.0` (Section 1 completed)
